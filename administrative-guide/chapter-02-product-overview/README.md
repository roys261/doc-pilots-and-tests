## Key Concepts

### Disaggregated vs. Appliance Models
- **VO (Disaggregated)**: Independent scaling of compute, storage, and software
- **VX (Appliance)**: Factory-integrated compute, storage, and networking

### BYOS Licensing
- **VO**: Bring-Your-Own-Subscription required
- **VX**: BYOS or OEM licensing options

### Management Planes
- **VO**: Dell Private Cloud Manager with DAP orchestration
- **VX**: VxRail Manager with state machine orchestration

### Deployment Type Immutability
- Deployment type is set during Day 1 and cannot be changed
- Selection must be made carefully based on requirements
