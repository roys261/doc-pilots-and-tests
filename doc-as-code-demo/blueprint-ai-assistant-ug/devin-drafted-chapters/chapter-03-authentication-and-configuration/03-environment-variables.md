# Environment variables

Use environment variables for CI/CD pipelines or automated environments.

- Set orchestrator URL:
export BPA_ORCHESTRATOR_URL=" <https://your-orchestrator.example.com> "

- Set the tenant:
export BPA_TENANT=" <your-tenant-id> "

- Set the credentials:
export BPA_CLIENT_ID=" <your-client-id> "
export BPA_CLIENT_SECRET=" <your-client-secret> "
