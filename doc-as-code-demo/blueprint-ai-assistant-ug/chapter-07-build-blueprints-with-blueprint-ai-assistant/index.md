# Chapter 7: Build blueprints with Blueprint AI Assistant

Build blueprints with Blueprint AI Assistant
Before building blueprints, plan and define the requirements.
> **NOTE:** This chapter uses VMware vSphere as an example for the commands and outputs.
Define blueprint requirements
Before creating a blueprint, clearly define:

Table 6. Define requirements
Category Definition
Purpose The type of infrastructure this blueprint deploys
Scope Inclusion and exclusion of components
Target environment On-premises data center, Kubernetes, or cloud
Constraints Budget, timeline, compliance requirements
Dependencies Requirement of external systems or services
Research existing blueprints using natural language prompts in the Blueprint AI Assistant . Describe the environment for which
you want to build the blueprint. You can prompt it to suggest similar blueprints.
