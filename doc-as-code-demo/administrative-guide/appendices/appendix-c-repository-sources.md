## Using Source Citations

Throughout this guide, critical information is cited to repository source files using the format:
> Source: <ref_file file="path/to/file" />

These citations allow you to:
- **Trace Information**: Follow information back to original engineering specifications
- **Verify Details**: Check current implementation details in source files
- **Understand Rationale**: Access the reasoning behind design decisions
- **Get More Detail**: Find more detailed technical information

### Document Hierarchy

1. **Product Vision Documents**: High-level product strategy and goals
2. **Architecture Documents**: Technical design and component relationships
3. **Engineering Requirements**: Detailed functional and non-functional requirements
4. **Story Specifications**: Implementation details and acceptance criteria
5. **Source Code**: Actual implementation (in src/ directory)
